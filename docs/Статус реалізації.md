# Статус реалізації SmartScreen

Дата оновлення: 18.05.2026

## Готово для демонстрації

- WPF/MVVM solution зі шарами Domain, Application, Infrastructure, App і Tests.
- Portable структура: `config`, `logs`, `screenshots`, `localization`, `themes`.
- Скріншоти: область, весь екран, активне вікно, вибраний монітор, скріншот із затримкою.
- After-capture pipeline: clipboard, file, quick actions, editor, AI.
- Capture workspace без окремих вікон для редактора й AI-панелі.
- Редактор: pen, marker, line, arrow, rectangle, ellipse, text, crop, blur, pixelate, undo/redo.
- AI: Gemini, OpenAI-compatible, OpenRouter/NVIDIA-compatible маршрути, timeout, cancellation, оптимізація зображення.
- Prompt-шаблони та користувацькі категорії через Settings UI.
- AI-провайдери додаються/редагуються/видаляються через Settings UI.
- Глобальні hotkeys, tray menu, first-run wizard.
- DPAPI-захист локальних API-ключів у `config/secrets.local.json`.
- Логування з маскуванням секретів.
- Portable publish script: `scripts/publish-portable.ps1`.
- Runtime ThemeService для dark/light/system режимів: основні brushes, glass-панелі, controls, lists/combo/popup та hover/focus-стани оновлюються з налаштувань.
- Runtime localization resources: JSON-файли завантажуються у WPF resources, головне вікно і верхній шар налаштувань можуть оновлювати текст після зміни мови.
- Unit та smoke tests для конфігів, prompts, hotkeys, logging, AI image pipeline, secrets, localization fallback і WPF resource loading.

## Частково готово

- Частина спеціальних декоративних кольорів редактора/overlay ще задана як конкретні значення, бо це палітра інструментів і службові selection-стани.
- Детальні тексти Settings UI, editor UI та first-run wizard ще не повністю винесені в localization keys.
- Є автоматизований WPF smoke test, але повні click-through UI-тести через Appium/WinAppDriver ще не додані.

## Backlog після MVP

- Повне винесення всіх UI-текстів у localization keys.
- Повна theme-дизайн-система без hardcoded кольорів у XAML.
- Імпорт/експорт workflow presets.
- Більш просунуті режими захоплення: window picker, color picker, ruler.
- Пакування installer/MSIX за потреби, хоча portable build уже доступний.
