# Статус реалізації SmartScreen

Дата оновлення: 18.05.2026

## Готово

- WPF/MVVM структура зі шарами Domain, Application, Infrastructure, App і Tests.
- Portable-папки: `config`, `logs`, `screenshots`, `localization`, `themes`.
- JSON-конфіги, fallback для відсутніх/legacy налаштувань, централізоване логування.
- Скріншоти: область, весь екран, активне вікно, конкретний монітор.
- Скріншот із затримкою як реальний сценарій з налаштовуваним таймером.
- Clipboard, PNG/JPG, quick actions workspace, after-capture pipeline.
- Редактор усередині overlay: pen, marker, line, arrow, rectangle, ellipse, text, crop, blur, pixelate, undo/redo, color/thickness/text size/fill.
- AI-панель усередині workspace: prompt templates, custom prompt, cancel, copy response, save response.
- Gemini, OpenAI-compatible, OpenRouter/NVIDIA-compatible маршрути через provider-архітектуру.
- AI image optimization, timeout, cancellation, дружні помилки провайдерів.
- AI providers: додавання, редагування, видалення і вибір активного провайдера через Settings UI.
- Prompt templates: додавання, редагування, видалення, reset defaults, власні категорії, видалення категорій із переносом prompt-ів.
- Глобальні hotkeys, tray menu, first-run wizard.
- Захист від дублювання вікон: Settings, capture workspace і region overlay не відкриваються повторно поверх уже активного екземпляра.
- Capture pipeline захищений від паралельного запуску під час hotkey-спаму.
- DPAPI-захист локальних API-ключів у `config/secrets.local.json`; ключі не пишуться в `appsettings.json`.
- Логування з маскуванням секретів.
- Runtime ThemeService для dark/light/system режимів: основні brushes, glass-панелі, controls, lists/combo/popup, capture overlay, editor toolbar/selection states та hover/focus-стани оновлюються з налаштувань.
- Runtime localization resources: JSON-файли завантажуються у WPF resources.
- Локалізовано головне вікно, dashboard/status рядки, tray menu/notifications, region overlay, first-run wizard, Settings UI, Settings statuses/validation, capture workspace, quick actions, AI-панель, основні tooltips редактора та статуси workspace/AI.
- Production portable publish через `scripts/publish-portable.ps1`; результат у `artifacts/SmartScreen-win-x64`.
- Unit tests для конфігів, prompts, hotkeys, logging, AI image pipeline, secrets, localization fallback.
- Localization completeness test перевіряє, що всі вбудовані localization keys є в `uk-UA.json` і `en-US.json`.
- WPF smoke tests для resource loading головного вікна та first-run wizard.
- Acceptance-style тести для after-capture pipeline: copy/save/workspace, editor-before-AI, AI startup, default monitor routing, friendly empty-state status.

## Частково

- Локалізація: основні екрани, tray, dashboard/status, workspace і Settings переведені на localization keys; ще залишаються окремі службові fallback-тексти й повідомлення низького рівня.
- Автоматизовані UI/acceptance тести: є WPF smoke tests і workflow-level acceptance тести, але повні click-through сценарії через Appium/WinAppDriver ще не додані.

## Не готово / поза MVP

- Повні click-through UI/acceptance тести реальних сценаріїв: зробити скріншот, натиснути copy/save/editor/AI через автоматизований UI-runner.
- Installer/MSIX. Portable release уже є, installer можна робити окремим етапом.
- Просунуті режими після MVP: window picker, color picker, ruler, workflow import/export.
