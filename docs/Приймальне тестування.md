# Приймальне тестування SmartScreen

Дата оновлення: 18.05.2026

Цей документ фіксує acceptance story для фінального захисту: що перевіряється автоматично, що перевіряється вручну, які докази варто зібрати для звіту.

## Автоматизований Release Gate

Команда:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\test-release.ps1
```

Скрипт виконує:

- `dotnet test` для unit, smoke і workflow-level acceptance tests.
- `scripts\publish-portable.ps1`.
- Перевірку portable artifact: `artifacts\SmartScreen Portable`, exe/dll, `config`, `localization`, `themes`, `logs`, `screenshots`, `release.json`, відсутність `config\secrets.local.json`.
- Перевірку setup artifact: `artifacts\SmartScreen Setup`, `Install SmartScreen.ps1`, `SmartScreen.ico`, README і checksums.
- Перевірку `checksums.sha256`.
- Install smoke у тимчасову папку.
- Перевірку Start Menu, Settings, Uninstall, Desktop і Startup shortcuts.
- Перевірку `install.json`.
- Uninstall smoke з `-KeepData`.

Очікуваний фінальний рядок:

```text
Release acceptance passed.
```

## Передумови Ручної Перевірки

- Windows 10/11.
- .NET runtime, якщо запускається framework-dependent build.
- Один реальний AI provider у Settings: Gemini, OpenRouter або NVIDIA/OpenAI-compatible.
- API key внесено тільки через Settings або environment variable.
- `logs/app.log` очищено або збережено окремо перед тестом.
- Усі старі екземпляри SmartScreen закриті перед перевіркою hotkeys.

## UX Acceptance Notes

- Головне вікно використовується для налаштувань, а не як обов'язковий центр щоденного сценарію.
- Основний сценарій після hotkey має вести у capture workspace без потреби відкривати dashboard.
- Контекстні панелі editor/AI мають бути напівпрозорими, компактними і не перекривати критичну частину скріншота.
- Текст у кнопках, списках і tooltip має читатися в dark/light themes.
- Final actions `Ctrl+C` і `Ctrl+S` у workspace мають застосовувати поточні правки editor перед copy/save.
- AI-запит виконується тільки після явної дії користувача.
- API key не має бути у `appsettings.json`, git diff, release artifact або логах.
